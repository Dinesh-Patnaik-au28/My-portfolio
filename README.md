# Dinesh Patnaik — Portfolio V5

V5 is an interactive product experience built around Dinesh’s application-builder and production mobile work. Builder Studio is the environment, the interaction, and the primary portfolio story.

## Core experience

- Interactive Builder Studio landing environment
- Requirement modules that compose a live mobile application concept
- Configure → compose → build → release feedback loop
- Hero-to-system zoom transition
- Primary Application Builder product story and multi-app generation
- Continuous F&B ordering, curbside, delivery, status, and tracking journey
- Replaceable `ProductionScreenshot` slots for real product imagery
- Interactive application architecture and release pipeline
- Editspace room reconstruction R&D sequence
- Responsive touch layouts, reduced motion, and self-contained system fonts

## Run

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
```
